## 项目简介

**TCUSTB Protocol** 是面向北京科技大学天津学院教务系统的 Java 后端项目，围绕身份认证、个人课表、班级课表以及教师课表等校园场景，提供统一的 API 接口。

项目通过学校统一身份认证系统完成教务登录，并在服务端维护学校会话，将教务页面中的信息整理为前端可使用的结构化数据。前端无需直接处理学校 Cookie、动态登录表单或原始教务页面，即可完成账号绑定与课表查询。

微信身份与教务身份相互独立：用户可以先登录微信小程序，再在“我的”页面主动绑定教务账号。

## 核心功能

### 微信小程序登录

- 如果想要交流，请加我qq：1956674550

### 教务身份认证

- 对接学校统一身份认证系统，支持无验证码及图片验证码登录流程。
- 登录前创建有效期为 **5 分钟**、仅可使用一次的认证挑战。
- 只有完成教务单点登录并验证受保护页面后，才签发工具箱会话令牌。
- 学校要求滑块验证时，明确提示使用学校官方登录页面，不尝试绕过交互验证。
- 在学生资料中的学号与登录账号一致时返回真实姓名；无法核验时保留为空。

### 个人课表查询

- 按日期查询当前登录学生所在周的课程安排。
- 统一返回星期一至星期日、每天六个时段的课表结构。
- 不缓存已完成的个人课表查询结果，重新查询可获取学校最新返回的安排。
- 无效日期、学校页面变化或查询失败均明确报错，不将失败伪装成“无课”。

### 班级目录与班级课表

- 提供班级目录、学校实际学期选项及指定班级课表查询。
- 班级目录以 JSON 快照保存，支持更新后无需重启读取。
- 班级课表使用当前用户的学校会话实时查询，并精确匹配班级名称。
- 保留同一时段内的全部课程记录，以及教师、教学周和教室信息。

### 教师目录与教师课表

- 提供学期、时间模式、院系等筛选选项。
- 按学期与院系保存教师目录快照，减少重复采集。
- 实时查询指定教师的七日六时段课表，同名记录合并后按课程字段去重。
- 按日期查询时结合可核验的教学周筛选课程，周次无法核对时不声称当天无课。

## 技术与设计

| 项目 | 说明 |
| --- | --- |
| 开发语言 | Java |
| 运行环境 | JDK 17 或更高版本 |
| 构建方式 | Gradle Wrapper |
| 交付形式 | 可执行 JAR，使用 `bootJar` 构建 |

| 接口形式 | HTTP API，使用 Bearer 令牌访问受保护接口 |
| 学校会话 | 学校 Cookie 与动态表单参数仅保存在服务端 |
| 目录存储 | 班级及教师目录使用 JSON 文件快照 |
| 课表获取 | 实时查询，不缓存已完成的课表结果 |

### 服务流程

```text
校园工具箱 / 微信小程序
          │
          ▼
   TCUSTB Protocol 后端
          │
          ├── 微信登录与本项目会话
          ├── 教务账号认证与工具箱会话
          ├── 班级 / 教师目录快照
          └── 个人 / 班级 / 教师课表查询
                       │
                       ▼
             学校统一认证与教务系统
```

项目直接对接学校认证及教务系统，不调用 Shellbox。微信令牌与工具箱令牌相互独立，教务查询使用工具箱令牌。

## 主要接口

| 模块 | 方法 | 接口 | 用途 |
| --- | --- | --- | --- |
| 微信登录 | `POST` | `null` | 使用临时 code 登录 |
| 微信会话 | `GET` / `null` | `null` | 读取会话 / 退出登录 |
| 微信资料 | `POST` | `idk` | 保存昵称 |
| 教务认证 | `GET` | `/api/v1/identity/challenges?account=学号` | 创建登录挑战 |
| 图片验证码 | `GET` | `/api/v1/identity/challenges/{challengeId}/captcha` | 获取图片验证码 |
| 教务登录 | `POST` | `/api/v1/identity/sessions` | 验证教务身份并签发令牌 |
| 教务会话 | `GET` / `DELETE` | `/api/v1/identity/sessions/current` | 读取会话 / 退出登录 |
| 个人课表 | `GET` | `/api/v1/academic/my/schedule?date=YYYY-MM-DD` | 查询指定日期所在周的个人课表 |
| 班级目录 | `GET` | `/api/v1/academic/classes` | 读取班级目录 |
| 班级学期 | `GET` | `/api/v1/academic/classes/semesters` | 获取班级课表学期选项 |
| 班级课表 | `GET` | `/api/v1/academic/classes/{className}/schedule?semester=学期` | 查询指定班级课表 |
| 教师选项 | `GET` | `/api/v1/academic/teachers/options` | 获取学期、时间模式及院系 |
| 教师目录 | `GET` | `/api/v1/academic/teachers?semester=学期&college=院系值` | 获取教师名单 |
| 教师课表 | `GET` | `/api/v1/academic/teachers/{teacherName}/schedule?semester=学期` | 查询指定教师课表 |

受保护的教务接口需携带 `Authorization: Bearer <工具箱令牌>`，URL 中的班级名、教师名及其他参数需正确编码。

## 安全与隐私

- **凭据仅发往学校认证入口**：学校请求使用 HTTPS 并验证证书，密码不持久化。
- **学校会话不下发前端**：不返回学校 Cookie、动态登录表单参数或认证票据。
- **严格校验认证结果**：仅认证入口成功不足以证明教务登录成功，还需验证教务受保护页面。
- **限制回调范围**：拒绝未知来源的跳转，学校旧版 HTTP 回调仅在允许的教务来源及路径内升级为 HTTPS。
- **敏感信息不写入诊断日志**：避免记录密码、学号、令牌、Cookie 和学校返回页面，不开启 HTTP 线缆级日志。
- **教务会话有明确生命周期**：认证挑战及工具箱会话保存在内存中，进程重启即失效；工具箱会话有效期为两小时。

## 稳定性与错误处理

课表查询只合并同一学校会话、班级、年级、学期下的在途请求，不缓存已完成的结果；学期选项缓存一分钟。

只读学校请求包含重定向与可选重试，总等待上限为 **35 秒**。短暂网络错误，或未声明 `Retry-After` 的 `502`、`503`、`504` 响应，最多重试一次；登录失效、限流与超时不自动重试。前端课表与学期选项的等待上限为 **40 秒**。

接口通过固定错误码及经过清理的说明区分凭据错误、会话失效、学校繁忙、请求超时、页面格式变化等情况。前端应根据错误码展示友好提示，不直接显示学校 HTML，也不将异常结果解释为空课表。

## 快速启动

在项目根目录使用 JDK 17+ 和 Gradle Wrapper 构建。以下为 Windows PowerShell 示例：

```powershell
$env:JAVA_TOOL_OPTIONS='-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp'
.\gradlew.bat test bootJar
java -jar build/libs/TCUSTB-Protocol-1.0-SNAPSHOT.jar
```

如需启用微信小程序登录，应在启动前通过环境变量配置应用 ID 与密钥，不要将密钥写入代码或提交到仓库：

```powershell
$env:WECHAT_APP_ID='<你的小程序 AppID>'
$env:WECHAT_APP_SECRET='<你的小程序 AppSecret>'
java -jar TCUSTB-Protocol-1.0-SNAPSHOT.jar --server.port=8082
```

对公网提供服务前，应配置 HTTPS 和限流。上述命令为启动说明，不代表本文已完成真实账号登录验证。

## 使用边界

班级与教师目录来源于学校课表页面，只反映相关学期页面中出现的班级和教师，不等同于完整学籍名单或全校教职工名册。学校接口、页面结构或认证策略发生变化时，需要相应适配。

本介绍依据提供的项目资料整理，描述的是面向学校教务系统的项目能力，不构成学校官方发布或授权声明。
